# Рабочие инструкции Codex

Общаться по-русски. Перед анализом или изменениями прочитать
[docs/HANDOFF.md](docs/HANDOFF.md), [docs/BACKLOG.md](docs/BACKLOG.md)
и актуальный верхний раздел [CLAUDE.md](CLAUDE.md).

- Изменения пользователя, сторонние submodule и __pycache__ не включать в свои коммиты.
- Единственный источник мода — этот подмодуль `bloodborne_pc/mods-src/BBSC`.
  Перед правкой/сборкой проверить status/HEAD и pin в родительском репозитории.
- Сборка, деплой и игровое подтверждение — разные статусы. Не закрывать баг по одному тесту кода.
- Сейвы не откатывать без просьбы; файлы игры только читать; settings.json целиком не выводить.
- Не завершать работающие игры для деплоя. Push и публикация — по просьбе.

## Проверки

Следовать [правилам выбора тестов](../../docs/TESTING.md). Запускать только затронутые
сценарии и прямые зависимости. Полные повторные прогоны без новых изменений
не нужны. Проверки сейвов/восстановления исключены из стандартного набора
по разрешению пользователя; реальные сейвы не менять.

## Быстрая сборка и деплой — предпочтение пользователя от 02.11.2026

Для локальной разработки и установки на ПК/ноут использовать
bb-coop-build-deploy-logs в быстром режиме: только изменённые компоненты,
для DLL — delta вместо полного пакета. Без verify-release, аудита файлов,
SHA256 ZIP/бинарников, сверки manifest и полного чтения установленного дерева.
Полный пакет запускать с BB_FAST_DEPLOY=1; не повторять тесты ради деплоя.
Сохранять бэкапы, пользовательские данные и запрет замены при работающей игре.
Успешный exit сборки/копирования обязателен. Это заменяет старые требования
файловых проверок обычного деплоя. Релизы и диагностика — отдельные запросы.
