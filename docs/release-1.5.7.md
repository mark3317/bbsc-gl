# BBSC-GL 1.5.7

## Русский

После гибели всей группы в Кошмаре охотника BBSC-GL сбрасывает временные флаги боя с Людвигом, чтобы повторная попытка началась с первой формы. После победы мод пропускает повтор ролика второй фазы. Стендовые проверки прошли. Игровая проверка остаётся открытой.

Совместим с [BBGL 1.5.7](https://github.com/mark3317/bbgl/releases/tag/v1.5.7). Закройте игру и лаунчер, затем распакуйте ZIP мода в папку с `Bloodborne.exe`. Для первой установки скачайте [полный архив BBGL](https://github.com/mark3317/bbgl/releases/download/v1.5.7/bbgl-1.5.7-windows-x64.zip).

## English

After a full party wipe in the Hunter’s Nightmare, BBSC-GL clears Ludwig’s encounter flags so the next attempt starts in phase one. After victory, the mod skips network replays of the phase-two cutscene. Targeted tests passed. In-game verification is pending.

Compatible with [BBGL 1.5.7](https://github.com/mark3317/bbgl/releases/tag/v1.5.7). Close the game and launcher, then extract the mod ZIP beside `Bloodborne.exe`. For a first installation, download the [full BBGL ZIP](https://github.com/mark3317/bbgl/releases/download/v1.5.7/bbgl-1.5.7-windows-x64.zip).
