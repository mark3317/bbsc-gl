# Подсказки о колоколах у лестницы — 05.11.2026

Запрос: убрать посланников с подсказками о Зовущем и Малом звонком колоколах
у лестницы во Сне охотника, поскольку предметы уже выдаёт мод.

Это не подарок 12101024, отключённый ранее: обе подсказки находятся в MSB,
Message 1121/1122 (оригинальные русские тексты проверены в msg/rusru).
У записей нет entity ID, EMEVD не обращается к ним по этому идентификатору.

`party/dream_hints.py` исключает две записи из списка событий карты
m21_00_00_00, перенумеровывает оставшиеся Message и сохраняет смещения всех
объектов/областей. Не удаляет только текст и не оставляет пустое взаимодействие.
Формат сверен с SoulsFormats MSBB EventParam:
https://github.com/JKAnderson/SoulsFormats/blob/master/SoulsFormats/Formats/MSB/MSBB/EventParam.cs

Лаунчер подключает преобразование через scripts/mods.py только при BB_COOP=1.
Источник логики — подмодуль, bundle-coop.py копирует модуль в coop/party.
Преобразуется последняя выбранная версия карты: сохраняются зеркало и изменения
пользовательских модов. Настройка отключения пользовательских модов не отключает
правку кооператива. Исходные игровые файлы только читаются; результат находится
в сгенерированном overlay. DLL и выдача набора через Блокнот не менялись.

Проверка `BB_GAME=<game root> python tools/test_dream_bell_hints.py` PASS:
реальные оригинальная карта/карта с зеркалом, отсутствие ровно двух подсказок,
все остальные события, модели, объекты и области сохранены; повторное применение;
настоящий CLI mods.py с отключёнными пользовательскими модами и без кооп-правки;
проверено, что исходная карта не записана. Это изолированная проверка overlay,
не игровой прогон. Сейвы/настройки не читались и не менялись.

Статус: исходники и целевые проверки готовы; сборка/установка не выполнялись,
на ПК работают две игры. Игры не завершались. Pin/commit/push не менялись;
посторонние изменения рабочего дерева сохранены. После установки проверить
отсутствие обоих посланников у лестницы и сохранение соседних подсказок в игре.
