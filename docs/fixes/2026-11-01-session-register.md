# Книга Нечистокровных: список текущей сессии — 01.11.2026

## Первая реализация

Bundled BBSC c11d31c (основной код 69008f6), standalone 4e4cdc6 / b02d3dd,
BBGL pin 4b1a44c. Установлено на закрытые ПК и ноутбук 17:24 МСК.
DLL SHA256 B165A30C25EAF8138EF05F9C9C8E5E1E714DBAC0BFCC95371FBA166E60137931.
Бэкапы: coop-dev/backups/session-register-20261101-172417 на ПК,
-172419 на ноутбуке. Предыдущая промежуточная установка заменена.

Книга (оригинальный goods 130) выдаётся вместе с комплектом после блокнота 120.
Существующему персонажу с блокнотом выдача произойдёт в своём мире вне сессии.
Оригинальные имя/иконка/анимация/доступность книги сохранены.
Список содержит своё сетевое имя и участников своей группы, место по убыванию
уровня персонажа, в колонке очков — уровень. При равных уровнях порядок по имени.
Одиночный персонаж в кооп-режиме видит себя. Офлайн-ограничение оригинальной книги
сохранено. Это не постоянный рейтинг и не подсчёт заслуг.

## Цепочка, подтверждённая статически на установленном CUSA03173 01.09

1. EquipParamGoods[130]: goodsUseAnim=27, opmeMenuType=8, не расходуется;
   enable_white/black/multi=1, disable_offline=1.
2. 0x018F6D70 читает opmeMenuType из строки goods (+0x3F).
3. Таблица 0x018F7690: индекс 7 (тип 8) ведёт к 0x018F72F2.
4. После штатных проверок UI ветка 0x018F7312..0x018F733E выбирает callback
   0x01BBC1E0, очередь создаётся вызовом 0x01C4A520 в 0x018F7460.
5. Callback 0x01BBC1E0 передаёт UTF-16 строку Ranking (0x049B47D8)
   в 0x01C1CDF0 (вызов 0x01BBC224). Здесь установлен функциональный entry-hook:
   55 48 89 E5 41 57, три целые инструкции, без относительных операндов.
   Важно: обычный GoodsExecutor не является надёжной точкой открытия меню.
6. Нативные задачи рейтинга вызывают sceNpScoreGetRankingByRange в 0x00CCEBCD
   (GOT 0x053E5258) и GetRankingByNpIdPcId в 0x00CCD828 (GOT 0x053E5248).
   GetBoardInfo: 0x00CD0046, GOT 0x053E5278. Обёртки подают строки группы
   перед заполнением родного окна, исходные функции сохранены для других досок.

Старые Lua RequestRankingBoard/IsRecvRankingData в 0x013350D0/E0 — заглушки;
они не являются рабочей цепочкой книги. Ресурсы Ranking/RankingPlayerStatus
существуют, но сами по себе не доказывают формат карточки персонажа.

## Данные и ограничения прототипа

Мод раз в секунду на игровом потоке считывает level из локального PlayerGameData
(+0x78), сетевое имя берёт из BB_SHADNET_NPID (fallback BB_USER_NAME).
Новый пакет SHAD 0x2B/version 1 идёт через существующий relay/P2P и envelope
с sender/session. Принимается только совпадающая ненулевая SessionKey; смена
сессии очищает список, сообщения выхода удаляют участника, TTL записи 5 секунд.
Сервер менять не требуется. Всем участникам для полного списка нужна новая DLL.

Провайдер включается при создании родного Ranking, захватывает ID первой доски,
другие доски оставляет оригиналу; защитный срок 10 минут после открытия.
Текущее окно получает снимок на каждый свой запрос. Принудительная перерисовка
при входе/выходе не добавлена: для обновления можно закрыть/открыть книгу.
Размеры NP структур: Rank 128, PlayerRank 136, NpIdPcId 44, BoardInfo 24.
Карточка экипировки не реализована: hasGameData=0, game-info пустой.
Подписи колонок и оболочка остаются оригинальными; содержимое очков — уровень.
BBSC_SESSION_REGISTER=0 отключает установку провайдера.

## Проверено и что осталось

Целевые C++ fixtures реального провайдера: сортировка, страницы, поиск себя,
нулевой ранг отсутствующего участника, неверные/чужие пакеты, TTL, выход,
смена сессии, границы доски; PASS. Реальная выдача комплекта/очередь уведомлений
и сохранение параметров оригинальных goods: PASS. DLL build exit=0.
На ПК и ноутбуке проверены совпадение DLL, client manifest, UTF-8 без BOM.
Staging синхронизирован. Полный порт/лаунчер/ZIP не пересобирались.

Игру не запускали. Native окно, отображение сетевых имён при разных настройках
имени, уровень и состав группы, отсутствие ошибки при выборе строки требуют
игрового подтверждения. Кодовые fixtures этого не подтверждают.

Минимальный прогон: загрузить персонажа с блокнотом в свой мир, дождаться книги,
собрать группу, открыть книгу у хоста и гостя. Ожидается две строки с именами и
уровнями, порядок по уровню. Выйти одним участником, спустя 5 с открыть книгу
снова: ушедшего нет. Если окно пусто/ошибка, собрать bbsc-mod.log, в нём есть
Session register: book used / board ... range ... rows ... total ... .
