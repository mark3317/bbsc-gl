# Видимость удалённых охотников

В журнале П1 за 05.11 в 00:07:33 у персонажей П2 и П3 стояло `chr=1`. После загрузки чаши в 00:07:41 оба имели `chr=0`; механизм восстановления повторил создание в 00:07:45, в 00:07:46 оба вернулись к `chr=1`. Пользователь видел только ник П3. По этим строкам нельзя установить фактические флаги отрисовки, прозрачность или координаты П3.

Проверка отсутствующего игрового персонажа остаётся отдельным путём восстановления. Для существующей копии мод теперь сопоставляет нативного участника с актуальной записью реестра сессии. В пакет состояния жизни добавлен необязательный признак того, что модель отображается у самого владельца. Старые пакеты по-прежнему обрабатываются. При свежем подтверждении от владельца и непрерывно выключенной отрисовке или нулевой прозрачности в течение 2,5 секунды восстанавливаются только выключенные поля местной копии. Отдельный путь после смерти учитывает состояние конкретного охотника. Загрузка, выход, умирающие участники, неоднозначные личности и короткие переходы не запускают визуальную коррекцию. При срабатывании в журнал пишется событие MODEL.
