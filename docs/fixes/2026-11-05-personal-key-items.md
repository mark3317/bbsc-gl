## Новые правила

По просьбе пользователя полностью удалено получение предметов по инвентарю хоста:
нет периодической рассылки, начального снимка, запроса или обработчика ответа.
Пакеты старых версий 0x29/0x2E игнорируются, номера зарезервированы.
Новые предметы приходят через свой подбор/покупку, своё событие награды или
существующий обработчик босса. Это не обещает награду за пропущенную победу.

Сохранены журнал полученных предметов, компенсация потерь при загрузке/возврате,
восстановление перед повторным призывом и ретро-проверка собственных квитанций.
Список 25 ID переименован в BbscPermanentKeyReceipts: он только сохраняет квитанции,
включая старые выдачи и три личных значка NPC. Формат/источники журнала не менялись.
Ранее полученные предметы не удаляются. Без собственной квитанции восстановление
не выводит владение из инвентаря другого игрока.
