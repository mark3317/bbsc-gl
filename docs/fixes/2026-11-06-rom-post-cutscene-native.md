## Исправление по уточнению пользователя

Пользователь предпочёл вернуть нативную обработку: начало загрузки после
катсцены. Поэтому отдельный наблюдатель окончания ролика/ожидание прибытия хоста
не используется. Полученный проверенный host packet32000000 на карте32 у
гостя передаёт выполнение ОРИГИНАЛЬНОМУ13201803 вместо standalone RequestRemo.

В существующем pre-event pass соответствующий живой instance один раз
продвигается native iterator012EF2E0 к оригинальной2002[7]. Предварительно
используется штатная очистка дерева условий012EBFF0, как в native12ECDC0.
Итератор владеет PC, своим буфером аргументов и подстановками. Сохраняется
присвоение местного executor10000 из оригинального12ECEF8. Прямой записи PC,
нового скрипта, собственного таймера ожидания, ручной записи сюжетных флагов и
вызова warp из мода в этом пути нет.

Далее оригинальный интерпретатор выполняет:

1.2002[7](32000000,0,10000,3): запуск ролика и native Remo wait condition.
2.1001[1](1): штатное ожидание кадра.
3.2003[2](9180,0) и2003[2](70002802,1): оригинальный хвост события.
4.2003[49](2802958): штатный WarpNextStage_Bonfire в Яаар’гуль.

Существующий stage hook уже принимает2802958 и проводит его через независимый
loader/admission. Постоянное follow-host не возвращается; отдельного ожидания
прибытия хоста нет. Разная скорость просмотра/пропуска ролика определяется
нативным ожиданием каждого участника.

Запрос привязан к world/host/source map/load, применяется только гостю в
независимом режиме и не повторяется от повторного пакета в той же загрузке.
Проверяются оригинальные directory/row, совпадение iterator root/file и row,
отсутствие подстановок, пять точных команд хвоста и права памяти. При изменении
мира/роли/карты/загрузки запрос отменяется; не найденный за30с instance также
отменяется, без запасного самодельного телепорта.

13201803 получает локальную native net-byte и изоляцию обоих форматов channel31
при независимом режиме: чужой continuation не может перескочить местный ролик.
Общий старт по проверенному host scene packet сохранён. Событие не добавлено
в общий allowlist типа0 и не превращено в свободный местный запуск по близости.
