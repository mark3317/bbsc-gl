## Изменение

- Vacancy повышает epoch, снимает owner и очищает только временные native
  death bits. Заголовок остаётся пригодным для публикации сброса всем peers,
  включая собственный процесс хоста; пустые блоки публикуются повторно.
- Первый offer после vacancy берёт свежую штатную native таблицу загрузки.
- Кэш lease не допускает новый native load. Координатор подтверждает visit
  каждого отправителя offer существующими полями BlockWire (visit и origin_map
  как peer ID для leases). Все получают epoch fence, но только подтверждённый
  собственный visit разрешает применять историю в текущей загрузке.
- Непрерывно занятая локация сохраняет смерти; streaming и передача владельца
  сохраняют прежнюю историю. Чаши разделены ritual/world; persistent boss/story
  flags и сейвы этим исправлением не меняются. Все участники должны обновить DLL.
