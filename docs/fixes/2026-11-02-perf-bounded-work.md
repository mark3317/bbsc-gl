# Ограничение работы мода в игровом потоке — 02.11.2026

Основание: perf-20261102-review (ноут: SharedProgress 1314 мс, scaling 372–461 мс, частые NPC/колокольные проверки). Это изменения реализации для следующего замера, не подтверждение прироста FPS.

## Изменения

- SharedProgress проверяет наличие новых разрешённых битов до копирования сейва. Уже установленные/запрещённые биты не проходят повторную политику, пустой merge возвращается без бэкапа/записи. Реальные изменения по-прежнему требуют успешного синхронного бэкапа перед записью; при ошибке результат -2 удерживает pending journal для повтора в обоих вызывающих путях. Форматы журналов, native save/commit и личные квесты не изменены. Добавлен отдельный профилируемый scope progress backup. Файловая работа при реальных изменениях остаётся синхронной; полного устранения I/O-пауз не заявляем.
- Scaling обновляет малое число HP/damage SpEffect rows при начале нового ключа, NPC stagger armor — максимум 128 строк за tick, проверяя прошедшие 2 мс каждые 8 строк. Одна системная операция может превышать этот бюджет, это не жёсткая гарантия 2 мс. Новый состав/настройки/истечение host данных перезапускают неполный проход с начала, завершённый ключ публикуется только после полного прохода. Используется исходный armor, множитель не накапливается. Stagger таблицы переходят к новому значению постепенно (для 11 тысяч строк порядка 90+ игровых кадров); HP/damage применяются в начале. Не меняет отдельный фоновый поиск таблиц.
- NPC LocalizeBbscQuestEvent сохраняет быстрый кэш экземпляров и добавляет индекс диапазонов на файл событий. Промах больше не вызывает линейный поиск с проверками памяти на каждом поле. Таблица проверяется одним диапазоном при построении; заголовок/строка/диапазон валидируются при использовании. Пересекающиеся диапазоны сохраняют приоритет исходного порядка строк. Обе структуры ограничены и очищаются при reload-finish перед событиями новой карты. Новый nested scope NPC event lookup.
- BellsAnywhere возвращается для посторонних goods до чтения session. Эффект не читается повторно; stack locals считываются из уже проверенного диапазона текущего потока без отдельных проверок каждого байта. Ограничения гостя, наличие Silencing Blank, native-yes, тип персонажа, HP и сохранённые ограничения остаются.
