## Source defects corrected

`bbsc_http.cpp::ReadData` used `claim_delivered_ms.exchange(NowMs())` for every
claim response. The exchange changed the deadline even when the log was skipped
because an earlier claim was already pending. Repeated retained responses could
postpone cleanup indefinitely. Use compare-exchange from zero, preserving the
first delivery. Serialize claim observation with lifecycle maintenance. Only an
idle private-server response arms this deadline; a late joined response still
retires its publication, and public-server replies do not alter this state.

`InstallBbscStopHooks` tried to install a second hook at 01ED07A0 after the
selected `CSMultiPlayMan.StopRequest` Sites hook had already patched it. All
three logs report `request observer unavailable`. Route the lightweight stop
observer through the existing TraceEntry owner before the research/capture
guard; remove the duplicate installation. Native stop policy is unchanged.

Both checkout trees contain these corrections. Existing unrelated differences
in the large core source are retained. No pin or commit changes in this task.
