# Late joining without a launch-time group — 04.11.2026

Status: built and installed on PC + laptop, 04.11.2026. Both launchers opened;
automatic discovery lists twin/test. No live gameplay confirmation. See HANDOFF
for backups and build composition; source-only statements below are historical.

The old launcher derived a shared secret/group from the launchers visible at
startup. The engine required unanimous confirmation from that immutable roster.
Enabling PLAY alone could launch a singleton but could not admit a later player.

The regular launch path now persists a per-player home configuration independent
of other launchers. Launcher presence refreshes a separate peer directory while
the game runs. The runtime resolves fresh peers for summons, preserving stable
account/UserId/name and existing native login/loopback connections. No manual
connection-check button or preassembled group is required. Configured FPS remains
untouched (the parallel FPS-settings fix is preserved).

`party/dynamic.py` implements world-owned authority, durable staged reservations,
per-member request receipts, provisional guest binding and confirmed snapshots.
Only actual pending/joined/departing participants occupy a world's roster. An
unrelated offline player never votes on another world's bell. Guest acquire and
competing host reservations serialize against the same guest journal. Native
room IDs are unique across independent hosts; stale-session commands are fenced.
Guest/native leave still drains memberships explicitly. No timeout releases a
world or guest. All pending bindings survive restarts; no timeout failover exists.

The loopback compatibility layer refreshes identity lookup as peers appear and
finds guest signs outside the current active room roster. Provisional reservations
cannot deliver claims until the host commits. The16-frame relay window, ordered
chunks, stream fencing, bounded queues and durable ingress acknowledgements remain.
Legacy/static invitations and the existing local-three scenario retain Engine.
The packaging file list includes dynamic.py; no packaging/build was run.
