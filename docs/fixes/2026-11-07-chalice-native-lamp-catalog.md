## Причина и штатный источник

Прежний BbscWorldAltarLampUnlocked разрешал гостю только Hall, пока в
bbsc_world_lamps не появлялся отдельный session discovery/snapshot для ритуала.
Начальное заполнение этой таблицы читало обычные лампы, но не исторические
лампы всех чаш. Поэтому отсутствие записи ошибочно трактовалось как пустая
чаша. Metadata94x00..05 не содержит отдельную группу ламп выбранного слота.

Original1.09:013B89B0 переключает выбранный алтарь;013BA788..98E вычисляет
map40+slot и через013BC710(1,40+slot,0,7) привязывает виртуальную12907
к постоянной группе ламп этого слота. Mapper использует собственные таблицы
04730C10/047314D0. Полученный index адресует man[+28]+index*125 при
index<man[+24]. Это штатная индексация, не поиск/скан памяти и не выбор
другого алтаря на хосте. Все20 форм флагов: offset800+20*lamp (lit),
810+20*lamp (menu unlock);0<=lamp<10. Формы сохранены раздельно.

## Изменение

При существующем dirty/load capture семи алтарей ReadAltar читает их лампы
через оригинальный mapper. Недоступная группа отменяет capture, а не создаёт
искусственное пустое состояние. Изменение только ламп увеличивает revision.
20бит передаются в прежнем зарезервированном u64 каталога: размер906байт,
число пакетов, период их прежней отправки и общий envelope не меняются.
Receiver проверяет диапазон маски и принимает её вместе с полным каталогом.

Перед штатным построением меню гостю устанавливаются точные native lit/unlock
флаги выбранного host slot. Новые подтверждённые session discoveries могут
дополнять их до следующего каталога. Отсутствие discovery-cache больше не
урезает исторический прогресс. Native zero означает реально пустую чашу.
При неизвестном каталоге сохраняется прежний запрет открытия, без выдуманного
Hall-only списка. World/ritual/catalog fences сохранены.

Удалены BbscWorldAltarLampBits/BbscWorldAltarLampUnlocked и их параллельный
допуск перехода. Гость после обновления native флагов использует то же
условие12907810+20*layer, что хост. Hall остаётся безусловной точкой оригинала.
Native меню, выбор строк, helper/promise, анимации и стадийная загрузка сохранены.
Хосту native флаги из каталога не проецируются; личный backup гостя остаётся
на существующем пути. Реальные сейвы и файлы игры не менялись.
