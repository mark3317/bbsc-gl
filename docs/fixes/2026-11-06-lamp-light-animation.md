## Причина и исправление

Оригинальные EMEVD/ESD прочитаны из установленной игры, без изменений.
common7100 и m29/12907010 ждут команду зажигания, затем вызывают
2004[14](10000,0,101170,0):10000 — местный охотник. События не входили
в изоляцию личных взаимодействий, поэтому чужой native channel31 мог
продвинуть их локальные условия. Дополнительно команды зажигания
70000200+map*10000+index не сохранялись при применении чужого снимка.

Теперь оба события локализуются на каждом шаге, включая native restart,
и блокируются существующими send/receive hooks для обеих схем channel31.
Команды зажигания сохраняют местные0/1 при применении снимка для обеих ролей.
Они не становятся запросами перемещения. common7000, native анимация,
таймеры и общий Lamps mask открытых точек остаются штатными.
