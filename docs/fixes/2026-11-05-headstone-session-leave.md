# Выход клиента из сессии при перемещении через надгробие

05.11.2026. Исправлено в исходниках; сборка, установка и игровой результат отдельно.

## Свидетельства

Снимки обоих работающих профилей: родительский
`out/coop-dev/runs/headstone-session-leave-20261105/pc`.
Сбор завершился без предупреждений, оба файла имеют `ChangedDuringCopy=true`.
Player 1 — гость, `run_20261105_222014.log`; Player 2 — хост,
`run_20261105_222015.log`. Время ниже — МСК.

- Гость: независимый режим активен с 22:41:13.916; после 22:45:32.234
  находится во Сне, хост остаётся в Центральном Ярнаме.
- 22:48:32.245: `persistence suspended for 20000 ms (host gone for 180 s)`.
- 22:48:35.540: хост сам запрашивает возврат во Сон, появляется там после
  загрузки; до отключения защиты гостя сессия хоста остаётся в состоянии 3.
- 22:48:46.648: гость выполняет native stage request, точка 2412951;
  сразу зарегистрирован native Stop из `0x013CDEFB` (возврат после CALL
  `StageTransition.Stop` в `0x013CDEF6`), состояние 6, reload phase 4.
- 22:48:51.614: гость переходит из 6 в 0 и прибывает в Центральный Ярнам.
- 22:48:56.707: Stop на хосте из `0x01789F9E`, затем состояние 0.

Причина этого выхода установлена: старый watchdog воспринимал отсутствие
удалённого персонажа в текущей карте как отсутствие участника сессии.
По истечении 180 секунд он временно возвращал штатные завершающие вызовы.
Перемещение гостя попало в это 20-секундное окно и вызвало настоящий Stop.
Это отдельный случай от ранее диагностированного неверного возврата во Сон.

## Исправление

В `TickBbscSessionEnd` watchdog отсутствующего персонажа сбрасывается,
если согласован независимый режим. Сбрасываются и `partner_seen`, и уже
запущенный таймер. Удалённый PlayerIns закономерно отсутствует в другой карте,
поэтому ни хост, ни гость не должны завершать сессию по этому признаку.

Проверки выхода в заголовок и вторжений выше этого участка продолжают работать.
Подтверждённый выход участника обрабатывает прежний `TickBbscSessionExit`;
native сетевые ошибки и освобождение состояния 7 не изменены.
Для прежнего режима без независимых перемещений таймер сохранён.

## Проверки и границы

`tools/test_session_partner_distance.py` исполняет production участок watchdog
с подставленными native Stop/Cleanup и управляемым временем. До исправления
проверка падает на завершении независимой сессии. После исправления проходит:
оба участника порознь более 180 секунд, сброс таймера до согласования режима,
сохранение прежнего таймаута и Stop/Cleanup для обычной сессии.

`tools/test_native_leave_release.py` проходит: native состояние 7 освобождается
однократно, активные и присоединяющиеся сессии сохраняются.

Проверка синтаксиса полного `bloodborne_re.cpp` в режиме `BBSC_MOD` и
`bbsc_relay.cpp` завершилась с exit 0; остаются прежние предупреждения компилятора.
`git diff --check` проходит.

Реальные сейвы, память работающих игр и игровые файлы не изменялись.
DLL в этом исправлении не собиралась и не устанавливалась. Нужен игровой
контроль на следующей общей сборке: разойтись более чем на три минуты,
затем переместиться через надгробие за обе роли без нового подключения.
