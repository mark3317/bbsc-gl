## Реальная цепочка игры

В read-only ELF найдена штатная цепочка:
`018C4F90(actor)` → `017DD0B0(item manager, actor handle, NPC info)` →
штатный бросок `01F1CA40` → создание предмета на теле `017D5320` →
существующие native take/give и журнал личного подбора.

Ранее исследованная функция award017DDC50 — другой путь: она сразу выдаёт
результат в инвентарь. Для добычи врагов новый код её не вызывает.

Два перехвата в текущем bloodborne_re.cpp:

- `018C5002`: CMP локального HP перед native death-loot call. Для гостя типа1
  в мире хоста сравнивается отдельный неизменяемый операнд HP1, включая уже
  умершего гостя. Настоящее здоровье/роль персонажа не меняются. Для недоступного
  личного NPC используется HP0: исходный JLE блокирует награду. У хоста, дома,
  у других типов и при отключённом GUEST_ITEMS сохраняется исходная проверка.
- `017DD193`: native запись гостевого фильтра в локальный frame. Для того же
  гостя фильтр обнуляется: исходный JE017DD764 ведёт к017DD9A4, где сохраняется
  полная **уже брошенная игрой** запись. Иначе эта ветка оставляла только
  guest-eligible предметы (например, пули/флаконы). PARAM-строки не меняются.

Проверяются байты обоих мест до установки; обработчики активны только после
успешной установки обоих. Ошибка оставляет розничную native добычу, пишет ошибку;
добавочного ручного броска в качестве fallback нет.

## Смерть и дубли

Native worker ДО HP-проверки проверяет actor+1E1 mask0x220000, включающую
бит0x20000. ПОСЛЕ native drop-call ставит OR0x22000, также включающий0x20000.
Эта штатная отметка конкретной жизни врага остаётся без изменений.
Повторный callback/ForceTreasure не бросает лот второй раз. При действительном
возрождении врага native сбрасывает отметку; тот же расходный лот снова разрешён.
Возрождение только игрока её не сбрасывает.

Удалены NoteBbscGuestEnemyDeath, очередь из64 лотов, TickBbscGuestDrops,
публикация work signal и выдача из echo hook. Следовательно, добыча не теряется
в прежнем раннем выходе dead/loading и не создаётся двумя производителями.
nameId0 больше не определяет, нужно ли вручную дать пули/флаконы.
Добыча остаётся на теле для штатного подбора, а не приходит автоматически за убийство.

Подарки событий/разговоров, boss rewards, комплект и журнал восстановления
сохраняют собственные существующие пути. Это целевой переход добычи врагов,
а не глобальное отключение award-hook или смена роли гостя на хозяина.
