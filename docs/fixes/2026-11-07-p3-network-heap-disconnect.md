## Условие штатного выхода

- Инициализатор `0x01FC2C18–0x01FC2C57` связывает запись пула `NETWORK`
  (имя UTF-16LE в `0x049B81CC`) со слотом аллокатора `0x05540438`.
  Штатная отложенная отправка в `0x01789870` выделяет память через этот
  же слот, вызывая виртуальный метод `+0x58` с размером пакета.
- В `0x0178A120–0x0178A136` при существующем контроллере сессии вызывается
  виртуальный метод `+0x38` аллокатора. При результате выше `0xFFFF` игра
  пропускает ветку. При результате меньше 64 КиБ она проходит к событию
  `OnIrregularLeaveSession` (`0x0178A367`, строка `0x0492E53C`) и к `Stop`
  (`0x0178A3A8`, адрес возврата `0x0178A3AD`). Это единственный вход к этому
  вызову `Stop` в исследованном потоке. Ветка лимита 1001 отложенного пакета
  вызывает `Stop` отдельно, с адресом возврата `0x01789812`.

## Расширение при штатной инициализации

Порт при запуске коопа меняет 14 → 16 МиБ в пяти профилях таблицы
`0x04736D40`, столбец 8. Связь столбца с `NETWORK` подтверждена релокацией
`0x05358D00` → `0x049B81CC`. Штатный код `0x01FC7870` выбирает запись по
имени и профилю и сам выделяет память. У П3 стартовый лог содержит отдельное
выделение direct memory на 14 МиБ. Профили с 30 МиБ и без `NETWORK` сохраняют
исходные размеры. При несовпадении сигнатуры или одного из пяти исходных
размеров загрузчик оставляет всю таблицу без изменений.

Дополнительная ёмкость составляет 2 МиБ на игровой процесс, до 6 МиБ в
трёхпрофильном прогоне. Порог 64 КиБ и исходные обработчики выделения,
освобождения и завершения сессии сохранены. Правка применяется один раз
при загрузке образа. Проверка на таблице из оригинального ELF подтвердила
изменение только пяти записей и отказ на несовместимом образе. Проверка
компилятором `src/probe.c` прошла.
