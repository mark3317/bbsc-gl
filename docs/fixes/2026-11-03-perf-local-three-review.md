## Приоритет продолжения

1. Разнести frame pacing: planned deadline/actual wake/flip/queue wait/render
   readiness; различать ограничитель и опоздавший игровой кадр. Сначала одна
   игра в той же сцене при60, затем три: нынешние логи не отделяют конкуренцию
   процессов от регрессии коопа. Не снимать/менять cap пользователю автоматически.
2. Подзамер PartyObserve и подопераций IsValidSos.Update/region queries;
   thread CPU отдельно от wall-time и correlation с конкретными slow frames.
   Bell/NPC остаются заметными; не снижать частоту gameplay/lifecycle без проверки.
3. Python relay/durable writer: queue age/depth, fsync latency, send backlog и
   CPU per process. Ранний аудит не заменяет измерений исправленной реализации.
