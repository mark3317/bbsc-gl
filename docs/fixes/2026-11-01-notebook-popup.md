200/205/225/111 в инвентарь и ту же очередь, до показа списка. Нет отдельного
BBSC-баннера при подборе. У уже начатых персонажей остаётся периодический fallback.

второй — runtime handle, для обычных goods пустой; handle блокнота не переиспользуется.

функцию выдачи: блокнот carried/storage, четыре записи очереди, повторный вызов,
уже имеющийся колокол, ошибка add, полный инвентарь, guest/foreign world — PASS.
