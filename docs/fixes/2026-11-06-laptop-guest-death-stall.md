## Место блокировки

Текущий мод не подменяет native death pipeline: входные death hooks только
записывают время. BeginBbscCoopDeath запускается через финальную native
PartyGhostDeath_2; watchdog после15с только диагностирует, без самостоятельного
возрождения/ручной очистки эффектов. Поэтому если штатная цепочка не отдаёт
управление финальному этапу, ни общий checkpoint, ни native lamp load не стартуют.

условий. Поэтому доказан застрявший участок native guest death→final handoff,
но не конкретная инструкция/условие, которое его удерживает. Связь с удержанием
кооперативной сессии — кандидат, не доказанная единственная причина.

Не считать это нормальным ожиданием конца боя: модовый spectate controller
ещё не запущен, и именно его отсутствие позволяет предупреждениям повторяться.
Для точного исправления нужен bounded trace native wait/_1/_2 и их условий
при сохранённой сессии, с исходным control flow. Возвращать прежний fake death/
