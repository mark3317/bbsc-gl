# BBSC-GL 1.6.1

## Русский

- Прогресс гостя привязан к слоту загруженного персонажа. При выходе в меню следующий персонаж не получает журнал предыдущего.
- При совместном возрождении мод выбирает карту назначения, готовит восстановление здоровья штатной загрузкой и закрывает прежнее состояние смерти на границе загрузки.
- Уточнён сброс попытки босса в чашах. При первом успешном проходе гостя через туман участники в той же области получают команду начала боя. Старые сообщения предыдущей попытки отбрасываются.

Совместим с **BBGL 1.6.1**. Закройте игру и лаунчер и распакуйте ZIP в папку с `Bloodborne.exe`. Для первой установки скачайте полный BBGL 1.6.1. Обновите все копии в группе.

В предыдущем игровом прогоне гость первым запустил бой со Стражами в чаше. Полный игровой повтор на 1.6.1 открыт, в том числе для группы из трёх игроков. Отдельный прыжок сюжетного Рома, задержка первой смерти гостя после загрузки и известный разрыв NETWORK остаются открытыми.

## English

- Guest progress follows the loaded character slot. Returning to the title menu and loading another character keeps each character’s journal separate.
- Co-op respawn uses the destination map, prepares native health restoration and clears the previous death state at the load boundary.
- Updates Chalice boss-attempt resets. A guest’s successful first passage through the fog starts the encounter for peers in the same area. Messages from earlier attempts are discarded.

Compatible with **BBGL 1.6.1**. Close the game and launcher, then extract the ZIP into the folder containing `Bloodborne.exe`. For a first installation, download the full BBGL 1.6.1 package. Update every player in the group.

A prior game session confirmed a guest could start the Merciless Watchers fight. Full gameplay verification on 1.6.1, including a three-player boss fight, is pending. Story Rom’s jump, the delay on a guest’s first death after loading and the known NETWORK disconnect remain open.
