# BBSC-GL 1.5.6

## Русский

При загрузке арены Людвига BBSC-GL сверяет местную и глобальную отметки победы. При расхождении проход через туман ориентируется на штатный глобальный флаг. Стендовые проверки прошли. Игровая проверка остаётся открытой.

Совместим с [BBGL 1.5.6](https://github.com/mark3317/bbgl/releases/tag/v1.5.6). Закройте игру и лаунчер, затем распакуйте ZIP мода в папку с `Bloodborne.exe`. Для первой установки скачайте полный архив BBGL.

## English

When Ludwig’s arena loads, BBSC-GL checks the local and global defeat flags. If the flags disagree, the fog entrance uses the game’s global victory flag. Targeted tests passed. In-game verification is pending.

Compatible with [BBGL 1.5.6](https://github.com/mark3317/bbgl/releases/tag/v1.5.6). Close the game and launcher, then extract the mod ZIP beside `Bloodborne.exe`. For a first installation, download the full BBGL ZIP.
