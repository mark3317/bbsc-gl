# BBSC-GL 1.5.5

## Русский

В Менсисе снимок мира задаёт положение лифта в Бездну до запуска событий карты. После загрузки положением управляет штатное событие лифта. Проверки на стенде прошли. Игровой прогон остаётся открытым.

Совместимая версия — BBGL 1.5.5. Закройте игру и лаунчер, затем распакуйте ZIP мода рядом с `Bloodborne.exe`. Для первой установки скачайте [полный ZIP BBGL](https://github.com/mark3317/bbgl/releases/download/v1.5.5/bbgl-1.5.5-windows-x64.zip).

## English

In Nightmare of Mensis, the world snapshot sets the Abyss lift position before map events start. After loading, the original lift event controls its position. The targeted checks passed. An in-game test is still pending.

Compatible with BBGL 1.5.5. Close the game and launcher, then extract the mod ZIP beside `Bloodborne.exe`. For a first install, download the [full BBGL ZIP](https://github.com/mark3317/bbgl/releases/download/v1.5.5/bbgl-1.5.5-windows-x64.zip).
