# BBSC-GL 1.4.0

BBSC-GL 1.4.0 is the co-op build bundled with **BBGL 1.4.0**. It removes obsolete build and integration files. Co-op gameplay and Party are carried over from 1.3.3. Party compatibility passed a test bench check. Co-op gameplay from the 1.4.0 archive is still open.

For a first install, download the [full BBGL 1.4.0 Windows ZIP](https://github.com/mark3317/bbgl/releases/download/v1.4.0/bbgl-1.4.0-windows-x64.zip). The separate `bbsc-gl-1.4.0-windows-x64.zip` contains the same DLL, injector, Party runtime, metadata and licences. To install it over **BBGL 1.4.0**, close the game and launcher, then extract it into the folder containing **Bloodborne.exe**. All co-op players need the same release on a shared LAN or VPN.
