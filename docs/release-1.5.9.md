# BBSC-GL 1.5.9

## Русский

- При известном составе мод ждёт сообщения о присутствии, даже если независимое перемещение недоступно.
- После смены состояния загрузки или выхода участника мод снова проверяет готовность. Статус смерти подтверждает её только в комнате и визите отправителя.
- В стендовых проверках прошли все четыре сценария, включая опоздавшее сообщение и уменьшение группы. Игровая проверка остаётся открытой.

ZIP мода предназначен для BBGL 1.5.9. Закройте игру и лаунчер, затем распакуйте архив в папку с `Bloodborne.exe` с заменой файлов. Обновите всех участников до 1.5.9 для согласованного сброса. Для первой установки скачайте [полный BBGL 1.5.9](https://github.com/mark3317/bbgl/releases/tag/v1.5.9).

## English

- The mod waits for presence from known party members even when independent travel is unavailable.
- Changes in loading state or party membership trigger a new readiness check. Death messages count only for the sender’s room and visit.
- All four regression cases passed, including delayed messages and a shrinking roster. In-game verification is pending.

The mod ZIP is for BBGL 1.5.9. Close the game and launcher, then extract the archive into the folder containing `Bloodborne.exe` and replace the existing files. Update the whole party to 1.5.9 for coordinated recovery. For a first installation, download the [full BBGL 1.5.9 package](https://github.com/mark3317/bbgl/releases/tag/v1.5.9).
