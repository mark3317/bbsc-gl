# BBSC-GL 1.4.1

BBSC-GL 1.4.1 is bundled with **BBGL 1.4.2**. While one guest is joining, Party withholds other summon signs and the game keeps signs it has already received available for a later attempt. The next summon can proceed after the first guest joins or the admission is cancelled.

Bench checks covered 325 combinations of host, roster and join order for one to five players. Five clients completed sequential joins, cancellation, a full room and rejoining over HTTP and Matching2. Live gameplay with this build remains unverified.

After a team wipe in a boss fight, each player uses the game's normal load to the last shared lamp while staying in the session. Fallen players still spectate while a teammate is alive. The first player to load back no longer interrupts the others. On boss retries, the guest's fog gate is restored and opens for entry after the host. Bench tests covered all six return orders for three players and 25 original boss entry events across the base game, DLC and Chalice Dungeons.

For a first installation, use the [full BBGL 1.4.2 Windows ZIP](https://github.com/mark3317/bbgl/releases/download/v1.4.2/bbgl-1.4.2-windows-x64.zip). The separate `bbsc-gl-1.4.1-windows-x64.zip` contains the matching DLL, loader, Party runtime, metadata and licences. To install it over **BBGL 1.4.2**, close the game and launcher, then extract the ZIP into the folder containing **Bloodborne.exe**. Use the same BBGL release on all PCs on the shared LAN or VPN.

## Русский

BBSC-GL 1.4.1 входит в **BBGL 1.4.2**. Пока один гость подключается, Party скрывает остальные знаки из поиска, а игра сохраняет уже полученные знаки. Следующий призыв доступен после входа гостя или отмены текущей заявки.

На стенде проверены 325 сочетаний хоста, состава и порядка входа для 1–5 игроков. Пять клиентов прошли последовательный вход, отмену заявки, заполнение комнаты и повторное подключение через HTTP и Matching2. Проверка этой сборки в игре ещё предстоит.

После гибели всей команды на боссе каждый игрок штатно загружается у последней общей лампы в той же сессии. Пока жив хотя бы один напарник, погибшие наблюдают. Возвращение первого игрока больше не прерывает загрузку остальных. На повторной попытке у гостя восстанавливается туман босса, а проход становится доступен после хоста. Стенд проверил все шесть порядков возвращения троих игроков и 25 оригинальных событий входа в основной игре, DLC и чашах.

Для первой установки используйте [полный Windows ZIP BBGL 1.4.2](https://github.com/mark3317/bbgl/releases/download/v1.4.2/bbgl-1.4.2-windows-x64.zip). Отдельный `bbsc-gl-1.4.1-windows-x64.zip` содержит согласованные DLL, загрузчик, Party, метаданные и лицензии. Для установки поверх **BBGL 1.4.2** закройте игру и лаунчер и распакуйте ZIP в папку с **Bloodborne.exe**. Всем участникам нужна одна версия BBGL и общая локальная сеть или VPN.
