# BBSC-GL 1.5.8

## Русский

После гибели всей группы сбрасываются временные флаги боя у боссов сюжета, DLC и чаш. В чашах сброс учитывает текущий ритуал и арену. Запоздавший снимок не перезаписывает флаги новой попытки. Стендовые проверки прошли. Проверка повторной попытки в игре открыта. При совпадении числового флага у двух арен чаши он сохраняется.

Совместим с BBGL 1.5.8. Закройте игру и лаунчер, затем распакуйте ZIP мода в папку с `Bloodborne.exe`. Для первой установки используйте полный Windows ZIP BBGL 1.5.8.

## English

After a full party wipe, BBSC-GL resets temporary encounter flags for story, DLC and Chalice Dungeon bosses. Chalice resets use the active ritual and arena. Late snapshots preserve the new attempt’s local flags. Targeted tests passed. In-game verification of retries is pending. If two Chalice arenas share the same numeric flag, the reset preserves it.

Compatible with BBGL 1.5.8. Close the game and launcher, then extract the mod ZIP beside `Bloodborne.exe`. For a first installation, use the full BBGL 1.5.8 Windows ZIP.
